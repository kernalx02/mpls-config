MPLS VPN Phase-by-Phase Configuration

Core, VPNv4, VRF, and CE Connectivity

Phase 1: IGP & MPLS LDP [cite: 1]

Establishment of the core backbone routing and label distribution.

Router P1

hostname P1

interface Loopback0
 ip address 2.2.2.2 255.255.255.255
 no shutdown

interface FastEthernet0/0
 description Link-to-PE1
 ip address 10.0.23.2 255.255.255.252
 no shutdown

interface FastEthernet1/0
 description Link-to-P2
 ip address 10.0.34.1 255.255.255.252
 no shutdown

router ospf 1
 router-id 2.2.2.2
 network 2.2.2.2 0.0.0.0 area 0
 network 10.0.23.0 0.0.0.3 area 0
 network 10.0.34.0 0.0.0.3 area 0

mpls label protocol ldp
mpls ldp router-id Loopback0 force

interface FastEthernet0/0
 mpls ip

interface FastEthernet1/0
 mpls ip

hostname P2

interface Loopback0
 ip address 3.3.3.3 255.255.255.255
 no shutdown

interface FastEthernet0/0
 description Link-to-P1

 no shutdown

interface FastEthernet1/0

Phase 2: MP-BGP (VPNv4) [cite: 4]

Configuring iBGP between PE routers to carry VPNv4 prefixes.

Router PE1

router bgp 100
 bgp router-id 1.1.1.1
 no bgp default ipv4-unicast
 neighbor 4.4.4.4 remote-as 100
 neighbor 4.4.4.4 update-source Loopback0

 address-family vpnv4
  neighbor 4.4.4.4 activate
  neighbor 4.4.4.4 send-community extended
 exit-address-family

Router PE2

router bgp 100
 bgp router-id 4.4.4.4
 no bgp default ipv4-unicast
 neighbor 1.1.1.1 remote-as 100
 neighbor 1.1.1.1 update-source Loopback0

 address-family vpnv4
  neighbor 1.1.1.1 activate
  neighbor 1.1.1.1 send-community extended
 exit-address-family

Phase 3: VRF & PE-CE Routing [cite: 5]

Creating Virtual Routing and Forwarding (VRF) instances for the customer.

Router PE1

ip vrf CUSTOMER_A
 rd 100:1
 route-target export 100:1
 route-target import 100:1

interface FastEthernet0/0
 description Link-to-CE1
 ip vrf forwarding CUSTOMER_A
 ip address 10.0.12.2 255.255.255.252
 no shutdown

router bgp 100
 address-family ipv4 vrf CUSTOMER_A
  neighbor 10.0.12.1 remote-as 65001
  neighbor 10.0.12.1 activate
  neighbor 10.0.12.1 as-override
 exit-address-family

Router PE2

ip vrf CUSTOMER_A
 rd 100:1
 route-target export 100:1
 route-target import 100:1

interface FastEthernet1/0
 description Link-to-CE2
 ip vrf forwarding CUSTOMER_A
 ip address 10.0.56.1 255.255.255.252
 no shutdown

router bgp 100
 address-family ipv4 vrf CUSTOMER_A
  neighbor 10.0.56.2 remote-as 65002
  neighbor 10.0.56.2 activate
  neighbor 10.0.56.2 as-override
 exit-address-family

Phase 4: Customer Edge (CE) [cite: 6]

Final configuration for customer site routers.

Router CE1

hostname CE1

interface Loopback0
 ip address 192.168.1.1 255.255.255.0
 no shutdown

interface FastEthernet0/0
 ip address 10.0.12.1 255.255.255.252
 no shutdown

router bgp 65001
 bgp router-id 192.168.1.1
 neighbor 10.0.12.2 remote-as 100
 address-family ipv4
  network 192.168.1.0 mask 255.255.255.0
  neighbor 10.0.12.2 activate
